# R_Toolkit (β version)

ImageJ macro toolset for calculating the roundness parameter R from particle images.
> **⚠️ This software is currently under development and released as a β version.  
> 機能は開発中であり、β版として提供されています。**

## About

R_Toolkit provides two ImageJ macros for semi-automatic measurement of particle roundness:

- **R_Lab**: Full-featured macro with scale calibration, particle detection, and version management
- **R_Calc**: Lightweight batch processor for high-throughput R calculation
